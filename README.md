# 혁신의숲 신규 기업 등록 — 1차 조사 키트

신규 기업 등록에 필요한 11개 항목(홈페이지·로고 / 사업자번호 / 대표자·SNS / 소개글 / 영문소개 / 카테고리 / 키워드 / 연락처 / 이메일 / 서비스 / 뉴스)을 클로드코드로 1차 조사하고, 사람이 검수한 뒤 어드민에 입력합니다.

**원칙 하나만 기억하세요 — 확인된 정보만, URL 조합 금지, 못 찾으면 비우기, 유사 사명 교차 확인.** 비어 있는 건 괜찮지만 틀린 정보가 등록되는 게 가장 위험합니다.

## 내가 볼 파일

| 역할 | 볼 파일 |
|---|---|
| 운영팀 | 이 README (아래 "조사하기") — 조사 규칙은 자동으로 적용되니 따로 읽을 필요 없음 |
| 프리랜서 (검수·어드민 입력) | `검수_사용가이드_프리랜서용.md` + `기업등록/검수작업대.html` + 운영팀이 준 JSON |
| 운영매니저 | 위 전부 + `HANDOFF.md` (배경·사고 사례·남은 일) |

## 조사하기

### 처음 한 번만 — 준비

1. **이 페이지에서 파일을 내려받습니다.** 오른쪽 위 초록색 **`Code`** 버튼 → **`Download ZIP`**. 내려받은 압축을 풀어서 원하는 곳에 둡니다 (예: 바탕화면에 `기업등록조사` 폴더). 폴더 이름은 아무거나 괜찮습니다.
2. **클로드코드 앱을 열고, 작업 폴더로 방금 압축을 푼 폴더를 선택합니다.** (클로드코드는 항상 "어느 폴더에서 일할지"를 먼저 고르게 되어 있습니다.)
3. 끝입니다. 그 폴더 안에 조사 규칙 파일이 들어 있어서, 클로드코드가 폴더를 열 때 스스로 읽어 갑니다. 따로 설치하거나 설정할 것은 없습니다.
   - 폴더 안에 `.claude`라는 숨김 폴더가 있는데 탐색기에서 안 보여도 정상입니다. 지우지만 마세요.
4. **기업 ID(CORP_ID) 자동 조회를 쓰려면** 클로드코드에 혁신의숲 MCP(Innoforest Hub)가 연결돼 있어야 합니다. 연결이 안 돼 있으면 조사는 그대로 되지만 CORP_ID만 비어서 나오고, 검수자가 어드민에서 확인해 직접 넣게 됩니다. 연결 방법은 내부 가이드를 확인하세요.

### 매번 — 조사

클로드코드 채팅창에 이렇게 칩니다:
```
/company-research 기업명 / 사업자번호 / 대표자명
```
- 사업자번호·대표자명은 없으면 생략 (있으면 정확도가 크게 올라감). 기업 ID를 이미 알면 같이 적어도 됨
- 여러 기업이면 줄바꿈으로 이어서 입력. "OO기업 조사해줘"라고 해도 실행됨
- 결과: 채팅에 JSON 출력 + `기업등록/결과/`에 파일 저장. JSON 아래 **보고 사항**(못 찾은 항목, 유사 사명 주의)을 꼭 읽을 것
- 기업 ID는 요청에 적어 줬으면 그 값을, 안 줬으면 혁신의숲 DB에서 찾아 **사업자번호가 일치할 때만** 채웁니다. 확신 못 하면 비우고 후보를 검수 포인트에 적습니다
- 결과 JSON은 프리랜서(검수 담당자)에게 파일로 전달. **저장소에는 올리지 않음** (개인 이메일 후보가 섞일 수 있어 `.gitignore`로 막아 둠)

## 검수하기

검수작업대: [기업등록/검수작업대.html](https://github.com/markncompany-ai/new_company_AIresearch/blob/main/%EA%B8%B0%EC%97%85%EB%93%B1%EB%A1%9D/%EA%B2%80%EC%88%98%EC%9E%91%EC%97%85%EB%8C%80.html) — GitHub에서 열면 코드로만 보입니다. 위 링크 페이지 오른쪽 위 **다운로드(⬇) 버튼**으로 파일을 받아 더블클릭하세요. (ZIP으로 전체를 받았다면 `기업등록` 폴더 안에 이미 있습니다.)

1. `기업등록/검수작업대.html`을 더블클릭해서 브라우저로 연다 (설치 없음)
2. 📂 JSON 파일 열기로 결과 파일을 불러온다 (여러 파일 동시 선택 가능)
3. 맨 위 CORP_ID 칸 확인 — JSON에 기업 ID가 있으면 자동으로 채워져 있음. 비어 있으면 어드민에서 발급받아 직접 입력 (검수 포인트에 "cp 미확정"이 있으면 운영팀이 후보를 찾았지만 확신 못 한 것 — 후보 ID를 어드민에서 확인 후 입력)
4. 기업별 카드를 색상 순으로 검수 — 🟢 확실 → 그대로 / 🟡 확인권장 → 훑어보기 / 🔴 확인필요 → 반드시 직접 확인
5. 항목별 복사 버튼으로 어드민 입력. 뉴스는 일괄복사 → 엑셀 양식

특히 조심할 것: 대표자 SNS(동명이인), "검수 필요" 이메일, 유사 사명, 서비스의 앱 퍼블리셔가 이 기업이 맞는지. 자세한 건 `검수_사용가이드_프리랜서용.md`.

## 규칙을 바꿀 때

조사 규칙은 **조사 규칙 파일(`.claude/skills/company-research/SKILL.md`)과 검수작업대 HTML 두 곳에 같이 구현**돼 있고, 개발팀 스크래퍼에도 반영됩니다. 한 곳만 고치면 조사 결과와 검수 화면이 어긋나니 운영매니저에게 요청하세요.
