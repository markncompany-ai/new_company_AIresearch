# 혁신의숲 신규 기업 등록 — AI 1차 조사 키트

혁신의숲에 신규 기업을 등록할 때 필요한 11개 항목(홈페이지·로고 / 사업자번호 / 대표자·SNS / 소개글 / 영문소개 / 카테고리 / 키워드 / 연락처 / 이메일 / 서비스 / 뉴스)을 Claude로 1차 조사하고, 사람이 검수한 뒤 어드민에 입력하는 프로세스의 **전체 구성물**입니다.

**완전 자동화가 목표가 아닙니다.** 기계가 후보를 찾고 사람이 승인합니다. 핵심 원칙은 하나 — **확인된 정보만, URL 조합 금지, 못 찾으면 비우기, 유사 사명 교차 확인.**

> 인수인계 배경·사고 사례·검증 이력·남은 일은 [HANDOFF.md](HANDOFF.md)에 있습니다. 처음 보는 분은 이 README → HANDOFF.md → 팀원_사용가이드.md 순으로 읽으세요.

## 업무 흐름

```
① 기업 목록 준비 (기업명 필수 / 사업자번호·대표자명 있으면 정확도 크게 상승)
        ↓
② Claude 1차 조사 — 클로드코드 스킬 또는 웹 클로드 지시문 → JSON 출력
        ↓
③ 검수작업대.html — JSON 붙여넣기 → 기업별 카드로 검수 (초록=확실 / 노랑=확인권장 / 빨강=확인필요)
        ↓
④ 보조 처리 — 소개글 도우미로 카테고리·키워드 확인, 로고 256px 다운로드
        ↓
⑤ 어드민 입력 — 항목별 복사 버튼 / 뉴스는 일괄복사 → 엑셀 양식
```

## 시작하기

**클로드코드 (권장)**
1. 이 저장소를 클론하거나 다운로드
2. 저장소 폴더에서 클로드코드를 열고 `/company-research 기업명 / 사업자번호 / 대표자명` 입력
3. 채팅의 JSON을 복사 → `검수작업대.html`을 브라우저로 열어 붙여넣기 (결과는 `결과/`에도 저장됨)

**웹 클로드**
1. `표준지시문_원본_웹클로드용.md` 전체를 복사해 claude.ai 대화창에 붙여넣기
2. 맨 아래에 기업 목록을 적어 전송 → JSON 복사 → 검수작업대에 붙여넣기

자세한 내용은 `팀원_사용가이드.md`.

## 조사 규칙을 바꿀 때 — 반드시 4곳을 함께

규칙은 문서와 코드 여러 곳에 중복 구현되어 있습니다. 한 곳만 고치면 조사 결과와 검수 화면이 어긋납니다.

1. `.claude/skills/company-research/SKILL.md` (클로드코드 스킬)
2. `표준지시문_원본_웹클로드용.md` (웹 클로드)
3. `검수작업대.html` (파싱·표시·복사 로직)
4. 개발팀 스크래퍼 (`스크래퍼_CLAUDE_참고.md`로 전달)

## 최근 변경

### 2026-09-04 — 서비스 수집 규칙을 한벤투 로직으로 전면 교체
서비스 항목 규칙을 `참고/한벤투_서비스수집_로직.md` 기준으로 이식했습니다 (트리아지 → 탐색 순서 → URL 생존·귀속 검증 → 기록 원칙). 4곳 모두 반영.

- **JSON 스키마 변경**: `services` 항목이 `{type,name,url}` → `{name, nameEn, type(웹/앱/웹·앱), webUrl, playUrl, publisher, note}`. 서비스가 없으면 `services`를 생략하고 `servicesNote`에 확인 경로를 적음
- 검수작업대는 구양식 JSON도 자동 변환하고, `playUrl`의 `id=`에서 **패키지명(어드민 입력용)** 을 뽑아 복사 버튼을 제공
- 오프라인 시설·매장, iOS 앱스토어 URL은 **수집하지 않음** (운영매니저 확정)

### 2026-08-06 — 검수작업대 복사 버튼 무음 실패 수정
클립보드 API 실패 시 폴백 추가.

## 주의사항

- **`결과/`는 저장소에 포함하지 않습니다.** 조사 결과에는 개인 이메일 후보 등이 섞일 수 있어 사내 공유 경로로만 전달합니다. `.gitignore`로 막아 두었습니다.
- 팀원에게 zip으로 나눠 준 "공유팩"은 스냅샷이라 이 저장소보다 오래됐을 수 있습니다. **항상 이 저장소의 `main`이 최신입니다.**
- 검수작업대의 번역 버튼은 로컬 HTML에서 동작하지 않습니다. 영문 소개(`introEn`)는 조사 단계에서 채웁니다.
